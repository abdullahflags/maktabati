# مكتبتي

واجهة عربية من صفحة واحدة، ببيانات الفهرس من ملفك الأصلي. البحث والفهرس والإضافة والتعديل والاستيراد والتصدير تعمل داخل المتصفح، دون خادم لقاعدة البيانات.

## التشغيل

شغّل `node serve.mjs` داخل هذا المجلد ثم افتح الرابط الذي يظهر. لا تفتح `index.html` مباشرة؛ تشغيل الواجهة يحتاج خادم ملفات محليًا أو GitHub Pages. يلزم Node.js للتشغيل المحلي فقط؛ الموقع المنشور لا يحتاجه.

## النشر على GitHub Pages

ارفع محتويات هذا المجلد إلى مستودع GitHub. من Settings ثم Pages اختر Deploy from a branch، ثم الفرع main والمجلد root، واحفظ. ملف `.nojekyll` مضمّن. لا يحتاج الموقع بناءً أو تثبيت حزم. رابط الموقع سيكون وفق إعداد المستودع.

الموقع وجميع ملفاته، بما فيها الإكسيل الأصلي وأوراق التوثيق المضمّنة، ستكون متاحة لزوار الرابط عند النشر العام. تعديلات الزائر تخص متصفحه فقط؛ تعديل النسخة المنشورة يتطلب صلاحية الكتابة في مستودع GitHub.

## تحديث المكتبة

1. أضف الكتب إلى ملف الإكسيل أو عدّل سجلاته، مع الحفاظ على رقم الفهرسة للمادة الموجودة. للإضافة استخدم رقمًا جديدًا، أو اتركه فارغًا ليُنشأ تلقائيًا.
2. اضغط أيقونة الاستيراد. راجع أعداد الإضافات والتحديثات قبل التطبيق.
3. الدمج هو الخيار الافتراضي. الخانات الفارغة لا تمسح البيانات الحالية إلا إذا فعّلت خيار السماح بذلك. الاستبدال الكامل يتطلب اختيارًا وتأكيدًا منفصلين.
4. الأرقام المكررة في الملف توقف التطبيق حتى تصحيحها. وجود عنوان مطابق دون رقم يؤدي إلى مطابقته عند إمكان تحديد سجل واحد؛ العناوين المتشابهة ذات الأرقام المختلفة تبقى سجلات مستقلة.
5. احتفظ بنسخة إكسيل من زر التصدير. يمكن تصدير نتائج الفهرس المصفّاة وحدها.
6. لنقل التعديلات إلى الرابط المنشور: افتح «الملفات والحفظ»، ثم «تجهيز تحديث الموقع». ارفع ملف `data.js` الناتج بدل الملف الموجود في المستودع، وانتظر اكتمال نشر GitHub Pages.

التعديلات محفوظة في المتصفح الحالي. مسح بيانات المتصفح أو الانتقال إلى جهاز آخر لا ينقلها تلقائيًا؛ صدّرها أو انشرها أولًا. التراجع عن آخر استيراد متاح من «الملفات والحفظ» ويستبدل أي تعديلات أُجريت بعده.

## الإكسيل والبيانات

- الفهرس الأساسي يتضمن 12 حقلًا مطابقًا لملفك. لا تُملأ البيانات الناقصة بالتخمين ولا تُصحّح أسماء المؤلفين تلقائيًا.
- «تصدير الفهرس» ينشئ جدول بيانات بسيطًا قابلًا للتعديل وإعادة الاستيراد. «تصدير بيانات المكتبة» يضيف قوائم الاقتناء وأوراق التوثيق، كقيم محفوظة من المصدر؛ تقارير المراجعة ليست محسوبة من جديد.
- لوحتا «مكتبتي» و«حساب البحث» في ملف الإكسيل الأصلي واجهات وحسابات قديمة، لذا لا تُضمّنان في ملف التصدير الجديد. نسخة المصدر بكامل أوراقها وتصميمها محفوظة دون تغيير في `original-library.xlsx` ومتاحة للتنزيل من الواجهة.
- تحافظ الواجهة على القيمة النصية «الجزء الثاني» الموجودة في حقل عدد الأجزاء. لا تفترض أن هذا الحقل رقم دائمًا.
- عدد النسخ غير مسجّل لمعظم المواد، ولذلك لا يُعرض مجموع مضلل. إحصاءات الأسماء والمواضيع مبنية على القيم المسجلة، وقد تتضمن تهجئات متعددة للاسم نفسه.
- قراءة «مقروء» تشمل «ماجستير - مقروء»؛ المواد التي تجمع الرقمي والورقي تُحسب ضمن كل من المجموعتين.

## المكونات

مكتبة SheetJS CE 0.20.3 لتبادل الإكسيل مضمّنة محليًا من مصدرها الرسمي: https://docs.sheetjs.com/docs/getting-started/installation/standalone/ . تُحمّل عند الاستيراد أو التصدير فقط. لا توجد اتصالات تحليل استخدام أو خدمات بيانات خارجية.

خلفية المكتبة صورة مولّدة خصيصًا لهذا المشروع، مضغوطة بصيغة WebP إلى نحو 69 كيلوبايت. الوصف المستخدم: مكتبة معاصرة بأرفف بلوط فاتح، كرسي قراءة عاجي، وإضاءة نهارية هادئة، مع مساحة بيضاء تمتزج مع الصفحة. أُنشئت بأداة توليد الصور المدمجة.
